Card Wallet keeps your CNIC, driving licence and bank cards as photos and fields on the device in your hand. It opens behind a 4-digit code, and if you switch phones you move your data as one encrypted file — through Google Drive, Files or WhatsApp, wherever you choose.

Locked by four digits

The code is asked for when the app opens cold and again whenever it has been out of view for more than 30 seconds. Five wrong codes put a 30-second wait on the gate.

Backup is a file, not an account

Back up now writes one .cwbak file containing your cards and settings, sealed with AES-GCM 256 under a key stretched from your password. You keep the file.

Works with no internet at all

Aeroplane mode changes nothing: there is no first-party network request in the app, so nothing can leave the phone by itself.

Where your data actually lives

  1. 1Your cards

    Photos you took, plus the fields you typed. Saved in the app’s own storage on the phone.

  2. 2The lock

    A gate over the app. Your 4-digit code never leaves the device and is stored only as a salted digest.

  3. 3The backup file

    Encrypted with your password before it is written, then handed to the share sheet or your Downloads folder.

  4. 4Your choice

    Drive, Files, WhatsApp, a pen drive — wherever you put it. We never see it and cannot restore it for you.

Two things we would rather say plainly than bury: the 4-digit code locks the app, it is not the key that encrypts your stored cards; and a screenshot, a shoulder-surfer or a rooted phone is outside what any app can control.

Security, in detail

The backup file: what is done to it

Cards and settings are serialised, then encrypted with AES-GCM, 256-bit key. The key comes from your password through PBKDF2-SHA256, 150,000 rounds with a random salt; the salt, IV, algorithm and round count travel inside the file so any future version can open it. The password itself is never stored, so a lost backup password cannot be recovered — by us or by anyone else.

No plaintext path, ever

If a device cannot provide secure encryption, the app refuses to export and tells you why (its WebView needs updating). It will not quietly downgrade to an unencrypted file. A file without an encrypted block is refused on the way back in, for the same reason.

The 4-digit code

Stored on the device as a random salt plus a 600-round SHA-256 digest — never as the digits, and never in the backup file. That is why restoring on a new phone leaves the lock off: a new phone has to choose its own code. The digest is deliberately cheap so the gate does not delay the first frame on a slow phone; treat the code as a lock on the app, not as encryption of the stored data.

Forgotten code: what “Reset app” does

After five wrong codes the gate offers Reset app. It asks twice, says what it will erase, and then clears every card and setting on the phone. There is no backdoor and no support override by design — a hidden way in would be a hole for everybody else too. Your cards come back only if you have a backup file.

What the app never collects

No name, phone number, email, address book, location, analytics identifier or crash reporter. Card data is not uploaded. CVV and PIN are not asked for and not stored — the field is deliberately absent from the editor.

Switching phones in four steps

  1. Back up. Settings → Lock & backup → Back up now, choose a password, then save the .cwbak file to Drive or Files.
  2. Install Card Wallet on the new phone.
  3. Restore. Same card in Settings → Restore a file, pick the file, type the password.
  4. Set a new 4-digit code on that phone — the code belongs to a device, so it is not part of the file.

If the deck is large (20 photo cards is roughly 16 MB) and the phone’s storage is full, the restore stops with a message and leaves the cards already on the phone untouched.

Questions people ask

Can you see my cards, or look them up if I lose my phone?

No. There is no server behind the app, so there is nothing for us to look in.

Can you reset my 4-digit code?

No, and that is not us being unhelpful — the code is checked against a value on your phone only, so any way in for support would also be a way in for an attacker. You can turn the lock off in Settings as long as you can get in.

Is it safe to leave the backup file in Google Drive?

The file is encrypted with your password before it is written, so the copy in Drive is unreadable without that password. Treat the password as part of the backup: lose it and the file is useless.

Why no cloud sync or app login?

Sync means somebody’s server holds your ID photos and an account to break into. A file you keep yourself is smaller trouble: nothing leaves the phone unless you send it, and you can delete or move it whenever you like.

Which Android versions, and is it on the Play Store?

Right now it is a directly installed APK of about 11.7 MB; the store listing has not happened yet. The minimum Android version is set by minSdkVersion in the Android project and will be stated on the store page.

iPhone?

Not today. The app is built as an Android package.

What happens to my data if I uninstall the app?

It is removed with the app’s storage, which is exactly why the backup file exists. Take the backup before you uninstall — system backup (allowBackup) is switched off in the manifest so card data is not copied to Google’s storage behind your back.
