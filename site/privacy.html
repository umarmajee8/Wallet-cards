Card Wallet

Privacy

Short version: there is no account, no server and no analytics, so there is barely a privacy policy to read. The long version, in the order people ask.

What the app collects

Nothing. Card Wallet has no sign-up, asks for no email or phone number, and ships no analytics or crash reporting SDK. It makes no network request of its own — the card data, the photos and the settings never leave the device unless you send them yourself.

Where your cards are stored

In the app’s private storage on your phone: the card photos you took, the fields you typed, and the design settings. Android’s own “back up my data” mechanism is deliberately switched off for this app (allowBackup=false), so nothing is copied into a Google account behind your back.

The 4-digit code

The code is checked on the device and never stored as digits — only as a random salt and a digest of the code. It is not sent anywhere, and it is not included in your backup file. It locks the app; it is not the key that encrypts the stored data.

The backup file

Back up now encrypts your cards and settings with AES-GCM 256 using a key derived from a password you choose (PBKDF2-SHA256, 150,000 rounds) and hands you one .cwbak file. Where that file then lives — Google Drive, the Files app, a chat thread, a pen drive — is your decision and governed by that service’s own terms. We cannot read the file and cannot restore it for you: lose the password and the backup is gone. If a device cannot encrypt securely, the app refuses to export rather than writing an unencrypted file.

Permissions

Storage for the files you import and export, and the camera or gallery only when you tap to take a picture or pick one. Contacts, location and microphone are never requested. NFC is not enabled in this build.

This website

It is static files. It sets no cookies, uses no local storage except the theme switch you click, loads no fonts, scripts or images from any third party, and measures nothing. The links out to GitHub take you to GitHub, where GitHub’s own policy applies.

Talking to us

Questions go to the project’s issue tracker: github.com/umarmajee8/Wallet-cards/issues. Because there is no server, we cannot look anything up for you — but we can answer how it works.
